# Antartur Site

Migración de WordPress/Elementor a Next.js 100%.

## Stack

- Next.js 15 (App Router)
- TypeScript
- CSS Modules con Sass
- Node.js 20

## Desarrollo

```bash
# Usar Node 20
nvm use 20

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

## Estructura

- `src/app/` - Rutas (App Router)
- `src/modules/` - Módulos de dominio
- `src/components/` - Componentes UI genéricos
- `src/lib/` - Utilidades y helpers
- `src/styles/` - Estilos globales
